# Instruversal

A draw-to-music loop sequencer for desktop and phone. Draw on a canvas, a playhead loops across it, and your strokes become music.

## Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Test on a phone on the same Wi-Fi
npm run dev -- --host
```

## Tech Stack
- Vite + TypeScript
- Tone.js
- HTML5 Canvas 2D
- Plain CSS (Paper & ink design tokens)
